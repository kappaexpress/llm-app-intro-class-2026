# そもそも LLM とは

LLM = **Large Language Model** (大規模言語モデル)

- 「言語モデル」= 文章を扱うAIモデル
- 「大規模」= めちゃくちゃ大量のテキストで学習されている
- 中身は超巨大なニューラルネットワーク
- 代表例: ChatGPT / Claude / Gemini

---

# LLM の核心: 次のトークンを予測する

LLMがやっていることは、実はシンプル

- 入力された文章の **続き** として、次に来そうな単語を確率的に選ぶ
- それを1単語ずつ繰り返して文章を生成している
- 例: 「むかしむかし、あるところに」→ 次は「お」「昔」「人」…のどれが来そうか?
- 「賢く考えてから喋っている」ように見えて、根本は **続きの予測**

---

# 「トークン」という単位 (直感だけ)

- LLMは文章を「単語」よりも細かい **トークン** という単位で扱う
- 文字より細かい単位がある、というイメージだけでOK
- 文の長さがトークン数に影響する (=長いほど重い)
- 具体的な数値の目安・コスト計算・コンテキストウィンドウは **第6回** で扱う

---

# なぜそれで会話っぽくなるのか

- 学習データの中に **会話・QA・指示と応答** が大量に含まれている
- 「質問されたら答える」「指示されたら従う」パターンを覚えている
- だから「次に来そうなトークン」を出すだけで応答として成立する
- = 内部に「人間と会話する型」が染み込んでいる

# LLM が得意なこと

- 文章を **書く / 言い換える / 要約する**
- 翻訳
- アイデア出し・ブレスト
- コードの説明・雛形生成・バグの当たりをつける
- 形式変換 (箇条書きにする、JSON化する、表にする)
- 雑談・対話

---

# LLM が苦手なこと

- 正確な事実の保証 (もっともらしいウソを言うことがある)
- 最新の出来事 (学習時点までしか知らない)
- 厳密な計算・桁の多い算数
- 「自分が今何を知らないか」を正直に言うこと
- 一貫した長期記憶 (会話の外のことは覚えていない)

→ これらの「名前」と「対処」は **第2回** でまとめる

# 演習: いろいろ質問してみよう

得意・苦手を **自分で発見する**

- 得意ぽい例
  - 「この文章を3行で要約して」
  - 「Pythonで FizzBuzz を書いて」
  - 「カジュアルなメール文を堅い言い回しに直して」
- 苦手が出やすい例
  - 「今日のニュースは?」
  - 「12345 × 67890 は?」
  - 「自分のこと (受講生本人) について教えて」
  - 存在しない本・人物について聞く

---

# 演習で意識してほしい点

- **間違えることがある** ことを自分で確かめる
- **知らないことがある** (最新情報・固有情報) ことを確かめる
- 「もっともらしいけど嘘」がどんな顔で出てくるか観察
- 同じ質問の聞き方を変えると応答が変わることも体感

→ 第2回で「ハルシネーション」「知識カットオフ」として整理します

# おまけ: 「考えてから答える」モデル

世の中には Reasoning (推論) モデルというものもある

- 答える前に内部で **考える時間** を取るタイプのLLM
- 難しい問題 (数学・コード・推論) で精度が上がる
- 普通のLLMより遅い・コストが高い傾向
- 本コースで使う `gpt-5.4-nano` も **Reasoning対応**

今日は **「そういうのが世の中にある」だけ覚えておけばOK**
自分のコードから体感するのは **第4回**
