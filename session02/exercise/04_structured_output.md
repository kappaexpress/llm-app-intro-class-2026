# 04. 構造化出力 (JSON で返させる)

LLMの応答を **プログラムから扱う** には、決まった形式で返してもらう必要があります。
第4回以降のAPI連携で必須になる技術なので、今のうちに感覚を掴んでおきましょう。

---

## 例1: 自己紹介文からプロフィール抽出

```text
以下の自己紹介文から「名前」「年齢」「趣味」を抽出して、JSON形式で出力してください。
JSON以外のテキスト(前置きや解説)は一切出力しないでください。

入力: 「はじめまして、田中太郎です。28歳で、休日は登山と読書をしています」

出力フォーマット:
{
  "name": "...",
  "age": 0,
  "hobbies": ["...", "..."]
}
```

**期待される挙動**:

```json
{
  "name": "田中太郎",
  "age": 28,
  "hobbies": ["登山", "読書"]
}
```

この出力は Python なら `json.loads()` で辞書に変換できます。

---

## 例2: 商品レビューから感情と理由を抽出

```text
以下の商品レビューから、感情スコアと理由を JSON で抽出してください。
余計な前置きは書かず、JSONだけを返してください。

レビュー: 「デザインは可愛いんだけど、すぐ壊れた。値段の割にがっかり」

スキーマ:
{
  "sentiment": "positive | negative | neutral",
  "score": -1 から 1 の数値,
  "reasons": ["理由1", "理由2"]
}
```

**期待される挙動**: `sentiment` が `"negative"`、`score` が `-0.7` 前後、`reasons` に「すぐ壊れた」「値段の割にがっかり」などが入る。

---

## 例3: 文章からタスクリスト生成

```text
以下のメモから、TODOリストを JSON 配列で出力してください。
各タスクには ID(連番), タイトル, 優先度(high/medium/low) を含めてください。
JSON 以外は出力しないでください。

メモ:
「明日までに提案書を仕上げる。来週中に経費精算をする。
あと、いつか部屋の掃除もしないとな。提案書が一番急ぎ」

出力スキーマ:
[
  {"id": 1, "title": "...", "priority": "..."},
  ...
]
```

**期待される挙動**:

```json
[
  { "id": 1, "title": "提案書を仕上げる", "priority": "high" },
  { "id": 2, "title": "経費精算をする", "priority": "medium" },
  { "id": 3, "title": "部屋の掃除", "priority": "low" }
]
```

## 例4: ネストした構造

```text
以下のレストラン紹介文から、店舗情報を JSON で抽出してください。
JSON 以外は一切出力しないでください。

紹介文: 「渋谷駅から徒歩5分の『焼肉まつもと』は、ランチ1200円〜、
ディナー4000円〜の高コスパ焼肉店。座席は40席、個室も2部屋あります。電話: 03-1234-5678」

スキーマ:
{
  "name": "...",
  "location": {
    "nearest_station": "...",
    "walking_minutes": 0
  },
  "price": {
    "lunch_from": 0,
    "dinner_from": 0
  },
  "seats": {
    "total": 0,
    "private_rooms": 0
  },
  "phone": "..."
}
```

**期待される挙動**: 入れ子になった JSON が、スキーマ通りに正確に埋まる。

---

## 構造化出力のコツ

1. **スキーマをプロンプトに含める** — 期待する形を見せるのが一番早い
2. **「JSON 以外は出力しないでください」を明示** — これがないと前置きが付きがち
3. **フィールド名・型を固定する** — 「数値」「文字列」「配列」を明確に
4. **値の例を入れる** — `"sentiment": "positive | negative | neutral"` のように選択肢を見せる
5. **コードブロックに入れて見せる** — JSON を `json ... ` で囲んで例示しても良い

---

## やってみよう

例3のメモを自分の最近のTODOに差し替えて、ちゃんと優先度が妥当に振られるか確認してみてください。

**注意**: ChatGPT のWeb版だと、たまに JSON の前後に「以下が結果です:」のような前置きが付いてしまうことがあります。実務(API)では System Prompt や [Structured Outputs] という機能でこれを完全に防ぐ手段がありますが、今日は「プロンプトでお願いして極力守ってもらう」レベルで OK です。
