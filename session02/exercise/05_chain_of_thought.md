# 05. Chain of Thought (段階的に考えさせる)

LLMにいきなり結論を出させるのではなく、「**考える過程を1ステップずつ書き出してから** 答えて」と指示すると、複雑な問題で精度が大きく上がります。これを Chain of Thought (CoT) と呼びます。

---

## 例1: 文章題(CoT なし vs あり)

### CoT なし

```text
りんごが3袋あり、各袋には4個入っています。
2個食べた後、残りを5人で分けると、1人何個になりますか?
```

**期待される挙動**: モデルによっては「2個」と答えてしまうこともある(`3 × 4 = 12`、`12 - 2 = 10`、`10 ÷ 5 = 2` という正解への過程を端折る)。

### CoT あり

```text
次の問題を、考える手順を1ステップずつ書き出してから、
最終的な答えを「答え: 〜」の形で出してください。

問題: りんごが3袋あり、各袋には4個入っています。
2個食べた後、残りを5人で分けると、1人何個になりますか?
```

**期待される挙動**:

```
ステップ1: 3袋 × 4個 = 12個
ステップ2: 12個 - 2個 = 10個
ステップ3: 10個 ÷ 5人 = 2個

答え: 2個
```

中間ステップが明示されることで、計算ミスが減り、間違っていたとしてもどこで間違えたかが分かる。

## 例2: 論理パズル

```text
以下のパズルを、考える手順を順番に書き出してから答えてください。

A, B, C の3人がいます。
- A は B より背が高い
- C は A より背が高い
- B は170cm

この情報から、3人を背の高い順に並べてください。
ステップごとに「分かっていること」を整理しながら推論してください。
```

**期待される挙動**: 「Aは170cmより高い」「CはAより高いので最も高い」「順番はC > A > B」と段階的に推論される。

## 例3: 比較・意思決定

```text
東京から大阪への移動手段を「新幹線」「飛行機」「夜行バス」から1つ選びたいです。
判断基準は、(1) 所要時間、(2) 費用、(3) 快適さ の3つです。

ステップ1: 各手段について、3つの基準で評価する(表形式で)
ステップ2: 「ビジネスで翌朝大事な会議がある」前提で、どれが最適か理由つきで結論を出す

という手順で考えてください。
```

**期待される挙動**: まず比較表が出て、その後に前提に合った選択(おそらく新幹線か飛行機)が理由つきで提示される。

## 例4: コードのデバッグ

````text
以下のPythonコードはバグがあります。
ステップごとに「このコードは何をしているか」を読み解き、
最後に「バグ:」と「修正コード:」を出してください。

```python
def average(numbers):
    total = 0
    for n in numbers:
        total += n
    return total / len(numbers)

print(average([]))
````

````

**期待される挙動**: 「ステップ1: 合計を計算」「ステップ2: 個数で割る」「ステップ3: 空リストが渡されると len が 0 で ZeroDivisionError」というふうに整理され、修正コードが提示される。

## CoT を引き出すフレーズ

以下のようなフレーズをプロンプトに足すだけで CoT モードに切り替わります:

- 「**ステップごとに** 考えてください」
- 「**1段階ずつ** 推論してから答えてください」
- 「まず **分かっていること** を整理してから結論を出してください」
- 「**Let's think step by step.**」(英語の有名な呪文)

---

## CoT と Reasoning モデルの関係

- 最近のモデル(gpt-5.4-nano など、本コースで使うモデル)は、**裏側で勝手に CoT をやってくれる「Reasoningモデル」** になっています
- 第4回で API から `reasoning_effort` パラメータを切り替えるデモをやります
- ただし「プロンプトでCoTを促す」テクニックは依然として有効です(特に Reasoning を使わない軽量モデルで)
- どちらも「考えてから答える」という同じ発想です

## やってみよう

例4のコードを、自分が過去に詰まったコード(または下記の例)に差し替えて試してみてください。

```python
# 例: フィボナッチ数列を返したいが、なぜか毎回 [0, 1] しか返ってこない
def fib(n):
    result = [0, 1]
    for i in range(n):
        result.append(result[i-1] + result[i-2])
    return result[:n]

print(fib(5))
````

CoT 指示ありで投げると、`return result[:n]` で切り詰めている問題と、初期値2個を考慮していないループ範囲の問題、両方を順序立てて指摘してくれるはずです。
