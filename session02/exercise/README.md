# 第2回 演習: プロンプトエンジニアリング

この演習ではコードは書きません。**ChatGPT のWeb版** ( https://chatgpt.com/ ) を開いて、用意したプロンプトを順番に試し、応答を見比べてください。

## 進め方

1. ChatGPT のWeb版にログインする
2. このディレクトリの番号順にファイルを開く
3. 各ファイル内のコードブロックのプロンプトをコピーして ChatGPT に貼り付ける
4. 応答を読み、「期待される挙動」と比べる
5. 余裕があれば、自分でプロンプトを少し変えて違いを観察する

## ファイル一覧

| #   | ファイル                     | テーマ                            |

| 01  | `01_bad_vs_good.md`          | 悪いプロンプト vs 良いプロンプト  |

| 06  | `06_improvement_exercise.md` | **本番課題**: 3パターン書いて比較 |

## やるときのコツ

- **1ファイル = 1つの新しいチャット** にすると、前のやり取りに引きずられず比較しやすい
- 結果は紙やテキストファイルにメモしておく(後で振り返ると気づきが多い)
- 同じプロンプトでも2回投げると違う応答が返ってくることがある(LLMは確率的)
- 日本語でも英語でも構わないが、迷ったら日本語でOK

## 注意

- 個人情報・会社の機密情報は **絶対に貼らない**
- 演習用の架空データだけを使う
- 6番の課題で書いた3パターンとその応答メモは、次回までに自分の手元に残しておく
