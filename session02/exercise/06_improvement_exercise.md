# 06. 本番課題: 同じ目的を3パターンで書く

ここまで学んだ「役割」「具体的指示」「Few-shot」「出力フォーマット」「CoT」を実際に組み合わせてみる課題です。

---

## 課題

以下の **目的のうち1つ** を選び、それを達成するプロンプトを **3パターン** 書いて ChatGPT に投げ、応答を比較してください。

### 目的(どれか1つ選ぶ)

1. **書評生成**: ある本のタイトルとジャンルから、150字程度の書評風紹介文を作る
2. **議事録要約**: 雑談を含む会議メモから、決定事項と TODO を抽出する
3. **キャッチコピー生成**: ある商品/サービスから、SNS広告用のキャッチコピーを3案出す
4. **エラーメッセージ翻訳**: 英語のエラーメッセージを、初心者向けに日本語で「何が起きていて、どう対処すべきか」を説明する
5. **学習プラン作成**: ある技術(例: Docker)を学びたい初心者向けに、4週間の学習プランを立てる

(↑どれも気が乗らなければ、自分で目的を決めてもOKです)

---

## 3パターンの書き分け方

### パターン A: 雑に書いた版

- 目的だけを1行で書く
- 「いい感じに」「うまく」レベルの指示
- 例: 「Dockerを学ぶプランを作って」

### パターン B: 役割 + 具体指示を加えた版

- 「あなたは〜です」で役割を指定
- 数値・条件・対象読者などを明示
- 例: 「あなたはDevOpsエンジニアです。プログラミング歴1年の人向けに、Dockerを4週間で学ぶプランを作ってください。1週ごとに学ぶこと/手を動かす課題 を出してください」

### パターン C: B + Few-shot or 出力フォーマット指定まで加えた版

- 出力の構造を明示(JSON / 表 / 決まった見出し etc)
- 必要なら例(Few-shot)を入れる
- 場合によっては CoT も組み合わせる
- 例: 「あなたはDevOpsエンジニアです。... 以下のフォーマットで出力してください: `## 週N` の見出しごとに `### 学ぶこと` と `### 手を動かす課題` の小見出しを置き、それぞれ箇条書き3項目で...」

---

## ヒント

- 同じセッション(チャット)で3つ続けて投げると、前のやり取りに引きずられて比較しにくくなります。**3パターンは別チャットで** 試すのがおすすめです
- 1パターンにつき1回しか試さない、というルールはありません。気に入らなければ何度でも投げ直してOK
- 「期待通りの応答が出るプロンプト」より、「**なぜそれが効くのかを自分の言葉で説明できるプロンプト**」を目指してください
- ここで学んだ「効くパターン」は、第4回以降の API 呼び出しでもそのまま使えます
